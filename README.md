# Tugas Akhir 

Repository ini dibuat untuk memenuhi kebutuhan Tugas Akhir pada Program Studi Informatika, Universitas Udayana

---

## Fitur

- Login
- Registrasi
- Home
- Pencarian Jadwal Kapal
- Detail Jadwal
- Pemesanan Tiket
- Pembayaran
- E-Ticket
- Riwayat Tiket
- Profil

---

## Teknologi

- Kotlin
- Jetpack Compose
- Firebase Authentication
- Room Database
- Navigation Compose
- Lottie

---

## Cara Menjalankan Project

1. Clone / download project.

2. Buka Android Studio.

3. Open Existing Project.

4. Tunggu proses Gradle Sync.

5. Hubungkan emulator atau perangkat Android.

6. Klik Run.
